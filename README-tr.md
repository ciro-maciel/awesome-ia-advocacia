## Etiketler

Her öğe ne olduğunu anlatır. Yanındaki etiketler seçmeye yardımcı olur: resmi, standardı belirleyenden geldiğinde; açık kaynak, kodu yayımlandığında; ücretsiz veya ücretli, kullanım modeline göre; API ve SDK, entegrasyon yöntemine göre.
