## Метки

Каждый пункт объясняет, что это такое. Метки рядом помогают выбрать: официальный, когда это от того, кто задаёт стандарт; открытый код, когда код опубликован; бесплатный или платный по модели использования; API и SDK по способу интеграции. Пункты с меткой "от автора" сделаны Сиро Сезаром Масиэлом и подчиняются тем же правилам, что и все остальные.
