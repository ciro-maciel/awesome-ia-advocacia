- [Provimento 205/2021 da OAB](https://go.mymarketing.click/iaadv-provimento-205-2021-da-oab) - Aturan publisitas dan informasi dalam profesi advokat. `resmi` `gratis`
- [Recomendação 001/2024 do CFOAB](https://go.mymarketing.click/iaadv-recomendacao-001-2024-do-cfoab) - Rekomendasi Conselho Federal da OAB tentang penggunaan AI dalam advokasi. `resmi` `gratis`
- [Resolução CD/ANPD 19/2024](https://go.mymarketing.click/iaadv-resolucao-cd-anpd-19-2024) - Transfer internasional data pribadi, yang terjadi saat data ditempel ke layanan dari luar negeri. `resmi` `gratis`

## Label

Setiap item menjelaskan apa itu. Label di sampingnya membantu memilih: resmi jika berasal dari pihak yang menetapkan standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, serta API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan semua item lain.
