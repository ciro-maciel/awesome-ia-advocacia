- [Recomendação 001/2024 do CFOAB](https://go.mymarketing.click/iaadv-recomendacao-001-2024-do-cfoab) - La recommandation du Conseil fédéral de l'OAB sur l'usage de l'IA dans la profession d'avocat. `officiel` `gratuit`

## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand elle vient de l'organisme qui fixe la norme, code ouvert quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la façon de l'intégrer. Les entrées avec l'étiquette « par l'auteur » sont faites par Ciro Cesar Maciel et suivent les mêmes règles que toutes les autres.
